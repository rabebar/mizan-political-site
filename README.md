# مؤسسة الميزان السياسي

موقع مؤسسة الميزان السياسي للأبحاث والترجمة الإعلامية.

## النشر على Render

المشروع يعمل كخدمة Node لأن لوحة الإدارة تحتاج API لحفظ الأخبار والتحليلات.

إعدادات Render المطلوبة:

- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `ADMIN_USERNAME`: اسم مستخدم السوبر أدمن
  - `ADMIN_PASSWORD`: كلمة سر السوبر أدمن
  - `SUPER_ADMIN_USERNAME`: اختياري، لترقية حساب أدمن موجود مسبقًا إلى سوبر أدمن
  - `DATABASE_URL`: رابط PostgreSQL الداخلي لحفظ الأخبار والمدراء بشكل دائم

لا يوجد تسجيل أدمن مفتوح من الموقع. حساب السوبر أدمن يتم ضبطه من إعدادات Render فقط، ومن لوحة السوبر أدمن يمكن منح صلاحية أدمن تحرير أو سوبر أدمن لحسابات أخرى.

رابط لوحة الإدارة يكون عبر إضافة `#admin` إلى رابط الموقع.

## حفظ الأخبار والصور دون قرص Render

يمكن جعل مستودع GitHub منفصل هو مصدر الأخبار والصور الدائم، مع إبقاء هذا المشروع كخدمة Render عادية. لا تحفظ الخدمة أي صورة على قرصها المحلي عند تفعيل هذا الخيار.

1. أنشئ مستودع GitHub منفصلًا و**عامًا** للمحتوى، وأضف إليه `data/news.json` ومحتواه `[]`. يجب أن يكون عامًا لأن زوار الموقع يحتاجون إلى تحميل الصور.
2. أنشئ Fine-grained personal access token بصلاحية **Contents: Read and write** لهذا المستودع وحده.
3. أضف هذه المتغيرات في Render للخدمة:

   - `CONTENT_GITHUB_OWNER`: اسم حساب GitHub المالك.
   - `CONTENT_GITHUB_REPO`: اسم مستودع المحتوى.
   - `CONTENT_GITHUB_BRANCH`: اسم الفرع، افتراضيًا `main`.
   - `CONTENT_GITHUB_TOKEN`: الرمز السري، أضفه في Render فقط ولا تضعه في Git أو الموقع.

عند اكتمال المتغيرات الأربعة، يقرأ الموقع المقالات ويكتبها في `data/news.json`، ويرفع الصور إلى `images/` في مستودع المحتوى. التعديلات والحذف تنشئ commits في ذلك المستودع. صور المقالات عامة مثل محتوى الموقع نفسه. لا ترفع معلومات خاصة إلى مستودع عام.

يدعم رفع الصور بصيغ JPEG وPNG وWebP وGIF، بحد أقصى 6 MB لكل صورة. تظل حسابات المحررين الإضافيين والتحليلات مرتبطة بـ PostgreSQL؛ من دون قاعدة بيانات، استخدم حساب السوبر أدمن من متغيرات Render ولا تعتمد على حسابات محررين مخزنة محليًا.

بعد تفعيل GitHub content backend، اختبر نشر مقال وصورة ثم أعد نشر خدمة Render وتأكد أن المقال والصورة ما زالا ظاهرين. تجنب حذف مستودع المحتوى أو تغيير فرعه؛ فهو النسخة الأساسية للمقالات والصور.
